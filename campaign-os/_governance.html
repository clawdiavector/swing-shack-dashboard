Governance

The OS may observe, analyse, recommend, prepare — automatically. It may execute only with explicit human approval or an active automation policy that matches. By default, PAUSE / REDUCE / INCREASE / KILL / SCALE / RETIRE / CHANGE POSITIONING all require human approval.

Decision hierarchy

OBSERVE → VALIDATE → INTERPRET → RECOMMEND → HUMAN DECISION → EXECUTE → RECORD → REVIEW OUTCOME

Permission levels

Action authority defaults

Each action has a default authority source. Anything requiring HUMAN_ONLY cannot be authorised by an automation policy.
