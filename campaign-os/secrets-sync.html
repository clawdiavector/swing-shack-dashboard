🔐 Secrets Sync

Paste the contents of any credential JSON file from your Mac and Campaign OS will wire it up everywhere — file system, runtime env vars, and resolve caches. No Railway dashboard round-trip needed.

Step 1 — Pick the service

Step 2 — Paste JSON contents

On your Mac, open ~/.openclaw-instance2/workspace/clients/swing-shack/credentials/<service>.json, copy the entire contents, and paste here. The server writes to disk + env vars + clears resolver caches.
How to find the credential files on your Mac

Open Terminal and run:

cat ~/.openclaw-instance2/workspace/clients/swing-shack/credentials/meta-token.json | pbcopy

This copies the file contents to clipboard. Then come back here and paste into the JSON box above.

Repeat for each service. Order doesn't matter — sync each one separately.

What "wired" actually means

For each service, syncing does three things:

  1. Writes the JSON file to ~/.openclaw/workspace/credentials/<svc>.json on the server
  2. Writes the same file to /data/credentials/<svc>.json (survives deploy restart)
  3. Sets the matching env vars (e.g. META_ACCESS_TOKEN) in the running process

Step 3 is what makes it work immediately — no need to wait for a deploy. For permanent persistence across deploys, also add the same env vars to the Railway dashboard Variables tab.

Privacy: nothing is logged. The contents box above is sent over HTTPS only to this server's /api/admin/secrets-sync endpoint, which writes them to chmod-600 files in credential dirs that only Campaign OS reads. The browser never sees the keys again after you click sync.
