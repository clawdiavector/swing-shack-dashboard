🔌 Connect Meta (Facebook + Instagram)

Paste your Meta app credentials here. They land in ~/.openclaw/workspace/credentials/ with chmod 600 and are never logged, sent over the wire, or shared. Once submitted, Heidi verifies against Graph API and Campaign OS auto-restarts to pick them up.

App credentials (from developers.facebook.com/apps → Heidi → Settings → Basic)
Numeric, ~15 digits. Visible at the top of Settings → Basic.

If you have a page-scoped long-lived token instead, use that — paste the whole string, do not truncate.

Where do I find these values?

App ID + App Secret: developers.facebook.com → My Apps → Heidi → Settings → Basic.
Page ID + IG Business ID: In Graph API Explorer, set query to me/accounts?fields=id,name,instagram_business_account with a valid token, click Submit.
Token: In Graph API Explorer, click Generate Access Token after adding the 6 scopes listed above.
Page token (long-lived): In the me/accounts response, each page has its own access_token field — use that instead of the user token if you can.

Privacy: Values POST to http://localhost:8000/api/meta/credentials over your local network only. No third-party server, no telemetry. Files written to ~/.openclaw/workspace/credentials/ with chmod 600. After submit, Heidi will restart Campaign OS to load the new env vars; the form will display the Graph API verification result.
