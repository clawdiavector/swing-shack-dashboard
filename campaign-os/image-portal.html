Setting keys on Railway (production)

⚠ The keys you paste above only affect your local machine. To enable image generation on the live Campaign OS (Railway), you also need to set environment variables on the Railway dashboard.
  1. Open railway.com/dashboard
  2. Go to swing-shack-dashboard project → Variables tab
  3. Add (or update) these variables:
    OPENAI_API_KEY=your OpenAI key
    OPENROUTER_API_KEY=your OpenRouter key
    CAMPAIGN_OS_IMAGE_PROVIDER=openrouter
    CAMPAIGN_OS_IMAGE_MODEL=google/gemini-2.5-flash-image
  4. Click Deploy to push the new env vars. Railway will auto-redeploy.
  5. Come back to /image-lab and try Generate.
Where to get the keys:
• OpenAI: platform.openai.com/api-keys
• OpenRouter: openrouter.ai/keys
