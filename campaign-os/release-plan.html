M3
Core Loop
Verification + first agent write-backs + approval routing
🔴 BLOCKED — waiting on M2
What Gets Built
  • Clawfix verification service (6 rules: schema, field, consistency, blockedBy, history, ownership)
  • Copywriter write-back script (hooks/captions generated → writes to staging → Clawfix verifies → committed)
  • Postiz confirmation loop (dispatch → scheduled → live/failed → write-back)
  • Discord approval routing (cron checks approval-pending → sends @Christelle message with Approve/Reject buttons)
What Becomes Possible
  • Every copy asset write is verified before it enters campaign state
  • Christelle receives Discord notification when approval is needed — no discovering work
  • Publishing state reflects reality: scheduled → live or failed
  • Campaign Mothership starts showing live data as agents generate assets
Before: Christelle checks cockpit manually to find work. Approvals are discovered. Publishing state is unknown.
After: Christelle gets a Discord message — "Hook G needs approval." She clicks Approve or Reject. Done. The system comes to her.

M4
Fleet Wired
All remaining agents write back automatically
🔴 BLOCKED — waiting on M2
What Gets Built
  • ImageGen write-back script (visual generated → write to staging → Clawfix verifies → cockpit shows visual)
  • TruthCollector write-back script (daily analytics pull → writes engagement/conversion data → cockpit updates)

What Becomes Possible
  • Every agent action writes back to campaign-data.json automatically
  • Visual assets appear in Campaign Mothership production view as they're generated
  • Analytics data is current in the cockpit every morning (06:00 SAST)
  • Health ring reflects real-time campaign health — not a snapshot
  • Publishing state always reflects true platform status (live/failed)
Before: Christelle manually updates campaign state. Analytics are stale. Health is estimated. Visual pipeline is invisible in the system.
After: Every agent action flows back automatically. Cockpit shows current state of everything. No manual updates needed.
