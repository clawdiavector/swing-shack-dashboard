# Content formulas: poster and post

Christelle's two one-line formulas (29 and 30 Oct 2026). They don't add rules; they put the rules in
`SKILL.md`, the carousel design guide, the reality check and the sales check in one line you can score
against. Reels, stories and video ads use the third formula, in the `reel-formula` skill.

Wiki (full sources): `research/poster-design-formula-2026-10-29`, `research/post-design-formula-2026-10-30`.
Interactive pages: https://claude.ai/artifact/WAhHSE169VQRxU6eZ1j3aL (poster),
https://claude.ai/artifact/Rf7P9CEkkF6buUYxc2MDnc (post).

## 1. The poster formula: the quick check on any one frame

> **Poster = Message × (Hierarchy + Contrast + Order + Space + Depth)**

Message is a gate: 1 if the frame says one thing and asks for one action, 0 otherwise. The five factors
score 0 (missing), 1 (weak) or 2 (strong). **Post at 8 or more, with no factor at 0.**

| Factor | Rule | Check |
|---|---|---|
| Message (gate) | One idea, one ask, written for a stranger | Say it in one sentence; needing "and" means two posts |
| Hierarchy | Hook, context, detail; hook at least 3× the body size | Ask what was seen first, second, third |
| Contrast | 2–3 contrast pairs pushed to the extreme; text passes a contrast check | Greyscale it: does the hook still stand out? |
| Order | Few shared edges; information in 3–5 groups; left-align anything longer than a line | Rule along the edges, circle the groups |
| Space | Generous equal outer margins, nothing jammed to an edge | Anything touching by accident? |
| Depth | One lit subject, a floor, type overlapping it | Cover the type: is there still something to look at? |

Caps: 1 message, 1 main image, 2 fonts, 3 colours, 3 text levels, at most 5 groups.
Tests: zoom to 25% (hook and ask still read), view as a phone thumbnail, score it.

## 2. The post formula: the whole sign-off

> **Post = Gates × Idea × Craft × Sell**

| Factor | Pass when | Where the rule lives |
|---|---|---|
| Gates (0/1) | **Real** (exact product untouched, real venue, reality check passed if photoreal) · **True** (specs, price, every number sourced, badges backed by the stock list) · **Kind** (never mocks the golfer; confident, not needy) · **One brand** (Swing Shack Johannesburg only, Stick Paarl only, Bag Drop may name both) | `SKILL.md` §11, §12, §17; `reality-check` |
| Idea (0/1) | One visual idea and one dominant move, named in a sentence before layout; one of the 8 recipes, not the neighbour's | `SKILL.md` §1, §15, §16 |
| Craft (/50) | The ten-part creative score, each /5. **40/50 or more**; any hard fail overrides it | `SKILL.md` §18 |
| Sell (0/1) | One action, one lead lever, one CTA, claims tagged verified / medium / assumed | wiki `runbooks/diagnose-a-post-sales-check-2026-10-27` |

Craft rules you can measure: at most 3 text levels plus the logo (`post_qa.TEXT_BUDGET`), a floating product
100px or more above its shadow or touching it (`post_qa.LIFT_MIN`), one shape language, base + support + one
accent doing one job, unequal spacing (tight / medium / large), type mode A, B or C.

## 3. How to use them

1. Before layout: write the Message (poster) and the Idea (post) as one sentence each.
2. On every frame or slide: score the poster formula. Below 8, or any 0, fix it before going on.
3. Before showing the post: run the post formula in order (Gates, Idea, Craft, Sell). Any 0 stops it.
4. When showing it to Christelle, give both scores in one line, e.g. "Poster 9/10 · Post: gates pass,
   idea 'type behind the bag', craft 43/50, sell: DM keyword", and name the one memorable decision.
