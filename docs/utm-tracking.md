# UTM Tracking System - Hook ID Attribution

## Format
All outbound links from Instagram/TikTok must include:

```
https://swingshack.co.za/?utm_source=instagram&utm_medium=social&utm_campaign=round{N}&utm_content=hook-{letter}
```

## Hook IDs
| Hook | ID | Best For |
|------|-----|---------|
| Stats | hook-a | TrackMan data posts |
| Transformation | hook-b | Progress posts |
| Convenience | hook-c | Rain/shine posts |
| Distance | hook-d | Driver posts |
| Swing Speed | hook-e | Speed posts |
| Numbers | hook-f | Data posts |
| Price | hook-g | Membership posts |
| Slice | hook-i | Fix content |

## Campaign Naming
- `round1` - A/B Round 1
- `round2` - A/B Round 2  
- `organic` - Non-paid posts

## Examples
- Instagram Post: `https://swingshack.co.za/book?utm_source=instagram&utm_medium=social&utm_campaign=round1&utm_content=hook-a`
- TikTok: `https://swingshack.co.za/?utm_source=tiktok&utm_medium=video&utm_campaign=organic&utm_content=hook-e`

## Enforcement
- All new posts MUST include UTM params
- Historical posts retro-tagged in GA4 where possible
