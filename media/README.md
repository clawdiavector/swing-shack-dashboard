# Swing Shack Media Library

## Categories

| Folder | Description |
|--------|-------------|
| `inbound/` | All new photos (unsorted) |
| `facility/` | Indoor golf simulator setup, the physical location |
| `trackman/` | TrackMan launch monitor screens and data |
| `clubs/` | Golf clubs, golf bags, equipment |
| `customers/` | People golfing, customers in action |
| `golf/` | Golf balls, golf course, general golf |
| `logo/` | Swing Shack branding and logos |
| `misc/` | Other/unknown |

## Adding New Photos

1. Photos sent to Discord automatically land in `inbound/`
2. Review and categorize into appropriate folder
3. Update `categories.json` with tags

## Usage for Posts

When creating a post, pick from:
- `facility/` - for posts about the studio
- `trackman/` - for data/fitting posts
- `customers/` - for testimonials/social proof
- etc.
