# Brand Directory Schema (v1.0)

Every brand in Campaign OS gets a folder under `data/brand-directory/<brand-id>/` containing
**nine structured slots**. This schema is the contract the image + copy generators read against.

When Drive is wired in, files in `images/` get dissected by `_lib/image_dissector.py`
which writes back per-image layer specs into `visual-spec/`. Manual entries are also
accepted — see `_system/HOW-TO-ADD-A-BRAND.md`.

## Folder contract

```
brand-directory/<brand-id>/
├── README.md                    # brand one-pager (what it is, who it is for, what it is not)
├── images/                      # raw brand assets (will be downloaded here from Drive later)
│   ├── originals/               # untouched brand-bible source images
│   ├── ads/                     # paid social / display ad examples
│   ├── posts/                   # organic posts (square, story, carousel)
│   ├── banners/                 # web hero banners, email headers
│   └── logos/                   # logo variations (full, mark, mono, knockout)
├── copy/
│   ├── headlines.md             # headline bank with tone, pillar, intent tags
│   ├── captions.md              # caption bank per surface + tone
│   ├── ctas.md                  # CTA bank (hard + soft, per intent)
│   ├── hooks.md                 # hook bank (openers, scroll-stoppers)
│   └── taglines.md              # approved taglines + anti-taglines
├── voice/
│   ├── tone-rules.md            # tone do/dont per surface (educational, funny, etc.)
│   ├── do-say-dont-say.md       # word list (allowed/avoid/banned)
│   ├── punctuation-rules.md     # em-dash ban, pipes, sentence length, etc.
│   └── emojis.md                # approved emoji library per brand
├── visual-spec/
│   ├── archetypes.json          # named archetypes (e.g. "square-post-v1") with layout
│   ├── layer-rules.json         # where logo / headline / hero / CTA go per archetype
│   └── dissection-log.json      # image-by-image layer dissections (written by image_dissector)
├── palette/
│   ├── brand.json               # primary / accent / neutral hex codes (canonical)
│   ├── surface-overrides.json   # per-surface tweaks (e.g. story = brighter)
│   └── contrast-checks.json     # WCAG passes/fails per bg+fg pairing
├── typography/
│   ├── fonts.json               # font families, weights, source (Google Fonts / custom)
│   ├── scale.json               # type scale (h1, h2, body, caption) with px/rem
│   └── pairing-rules.json       # headline + subhead pairings
├── archetypes/
│   ├── surface-templates.md     # which archetype = which surface (square post, story, banner)
│   └── named-templates/         # one markdown file per named archetype (e.g. "post-grid-3up.md")
└── examples/
    ├── good.md                  # examples that nailed the brand (annotated)
    ├── bad.md                   # examples that missed (annotated, anti-patterns)
    └── inspiration.md           # external inspiration (links + notes — never copy)
```

## Index file (auto-generated)

`_system/brand-index.json` is regenerated by `_lib/brand_indexer.py` after any folder change.
It is a flat lookup of every brand's canonical fields so generators don't have to walk folders.

```json
{
  "swing-shack": {
    "primary_color": "#0F766E",
    "accent_color": "#F59E0B",
    "voice_id": "swing-shack",
    "archetypes": ["square-post-v1", "story-banner", "course-shot"],
    "image_count": 0,
    "last_indexed": "2026-07-28T20:10:00Z",
    "ready": true
  }
}
```

A brand is `ready=true` only when all four gates pass:

1. `voice/` has at least tone-rules.md + do-say-dont-say.md
2. `palette/brand.json` has primary + accent hex codes
3. `visual-spec/archetypes.json` has at least 1 named archetype
4. `copy/ctas.md` has at least 3 approved CTAs

Until then the generator falls back to voice_bible.json + best-effort defaults and flags
the output as `BRAND: PARTIAL` so copy is reviewed.

## Manifest endpoint

`/api/brand-directory/<brand_id>` returns the merged index + system-check status so
the dashboard can show a brand-readiness score per brand in the Brand surface.
