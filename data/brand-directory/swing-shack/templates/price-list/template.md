# ss-price-list — coaching rate card

Two-column explicit-wrap session rows (labels + prices) with the same chrome as ss-price-package.

## Platforms

Instagram post + story (centred block), Facebook `ig_post`.

## Copy fields

| Field | Role |
|---|---|
| `caption_hook` | Title (balanced wrap, ≤2 lines) |
| `price_labels` | Rows separated by `\|` or newline |
| `price_values` | Matching price rows |
| `cta` | Footer CTA |
| `accent` | Optional colour lock |

Tag `post_type: price_list` or pin `template_id: ss-price-list`.
